## ГЛАВНЫЕ ИЗМЕНЕНИЯ ОТ v2.5

**1. Монетизация — кошелёк, не подписка**

— 5 ₽ за каждое сообщение AI

— Платные инструменты с фиксированными ценами

— Стартовый бонус 50 ₽

— Минимум пополнения 100 ₽

— AI знает баланс, но не обсуждает

**2. Меню старта — 5 веток вместо общей квалификации**

— 🎯 fix_existing — мало заявок

— 🚀 start_from_scratch — запуск с нуля

— 📊 analyze_stats — есть статистика

— 🔍 check_competitors — посмотреть конкурентов

— ✏️ just_ask — свободный вопрос

Каждая ветка имеет свой автопромпт и свой маршрут работы.

**3. Каждый чат отдельный (как у ChatGPT)**

— Юзер видит список своих чатов, может вернуться

— Новый чат → меню старта

— Внутри чата ветка не меняется

— Переключение задачи = новый чат

**4. Парсинг и XLS — через историю чата**

— Не в системном промпте (раздувает контекст)

— Системные сообщения в истории с структурированными данными

— AI читает их как обычный контекст

**5. XLS-логика**

— Загрузка файла бесплатна

— Анализ платный — 50 ₽

— 50 ₽ покрывают разбор + первичные комментарии AI

— Дополнительные 5 ₽ за сообщение с разбором не списываются

**6. Без пропусков шагов**

— Все 10 шагов проходят последовательно

— Уровень меняет темп и подачу, не структуру

**7. Запрет на угадайку**

— Каждый ответ опирается на данные

— Без данных — предложение парсера, не ответ по существу

**8. Жёсткие фильтры на заголовки**

— Длина ≤ 50 символов (хард-фильтр)

— Цены любого вида запрещены

— Проверка перед выдачей

**9. Legacy пользователи без отдельного режима**

— Одноразовое приветствие после миграции

— Дальше — обычная работа

— Логика «остаток подписки → баланс» на стороне бэкенда

**10. Полные ссылки на объявления**

— При упоминании конкретного объявления — полная ссылка из HYPERLINK
