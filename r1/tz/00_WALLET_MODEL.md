## ВАЖНО ПО МЕХАНИКЕ

### Списание после успешного ответа
Деньги списываются **ПОСЛЕ** успешной генерации ответа AI, не до.
Если сервер упал — деньги остаются на месте.

### XLS — загрузка бесплатна, анализ платный
Юзер загружает файл → лежит бесплатно.
Юзер нажимает «Проанализировать за 50 ₽» → списание + разбор.

### Парсер — по ссылке
Юзер вводит URL выдачи Авито (с фильтрами).
Парсер обрабатывает эту выдачу.

### Мониторинг — разовая проверка
Не подписка. Запустил → получил отчёт → сам решил когда повторить.

### Регенерация ответа — нет
Кнопка «Сгенерировать ещё раз» **отсутствует**.
Не нравится ответ — переформулируй вопрос.

### Кнопка 👎 — тихий сигнал
Под каждым ответом AI — кнопка 👎. Без возврата денег.
Сигнал попадает в админку → Лера видит паттерны → улучшает промпт.

### Деньги не сгорают
Никаких сроков. Положенные деньги — твои навсегда.
Возврат — через поддержку.
