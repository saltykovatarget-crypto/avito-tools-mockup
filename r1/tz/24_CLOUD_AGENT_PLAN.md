## 1. ЧТО ПОНЯЛ ПРО ПРОЕКТ

**Продукт.** AI Авитолог PRO — позиционируется не как «сервис аналитики Авито», а как автономный ИИ-агент: мозг (LLM) + глаза (vision-анализ фото объявлений) + руки (инструменты `parse_niche`, `analyze_photo`, `generate_title`…) + память (контекст клиента). Роадмап автономности: советует → делает с подтверждением → ведёт аккаунт сам. Ценностное сообщение: «ИИ-сотрудник вместо авитолога за 50к/мес».

**Команда.** Лера — продукт, стратегия, контент. Иван — бэкенд и парсер.

**Парсер (решение зафиксировано, не пересматривается).** `curl_detail` как primary — у Ивана работает на 5/5 URL, это production-факт. Playwright + Xvfb — ограниченный fallback, держится наготове заранее. AccountPool + мобильные прокси — этап после MVP, но со сроком. Принцип: один аккаунт = один прокси = один стабильный профиль, без хаотичной ротации UA. Мобильный API Авито — отдельный R&D вне production.

**Открытые направления.** GEO-продвижение (чтобы нейросети рекомендовали сервис), Telegram-агент как псевдо-человек с воронкой чат → канал → сервис, резидентство Сколково, лендинг.

**Что реально лежит в репозитории.** `index.html` — мокап интерфейса на 1024 строки (чат, тёмная тема, фиолетовая палитра `#7C3AED`), `promo/` — Remotion-проект промо-видео, `r1/tz/` — четыре документа (20–23), `CLAUDE.md` — задачи и стек.

**Важное расхождение.** Документы ссылаются на `01_parser_integration.md`, `11_AI_SYSTEM_PROMPT.md`, `15_PARSER_VISION_ARCHITECTURE.md` — этих файлов в репозитории нет. Скорее всего они в Obsidian у Леры. Без них облачная сессия не видит ни системный промпт агента, ни vision-архитектуру — а это ядро продукта.

## 2. ПЯТЬ ЗАДАЧ, КОТОРЫЕ ДВИГАЮТСЯ БЕЗ ДОСТУПОВ

Отсортировано по пользе на единицу затраченного времени.

### 1. `llms.txt` + структура GEO-контента (задача №1 в CLAUDE.md)
Написать черновик `llms.txt` для AI Авитолог PRO, карту тем, которые нейросети должны цитировать, и структуру JSON-LD. Не требует доступа к сайту — `/geo audit` запустится позже, когда сайт откроется, но фундамент готовится сейчас.
**Ограничение:** финальный аудит невозможен без живого URL.

### 2. Легенда и системный промпт Telegram-персонажа
Имя, биография, тональность, границы («никогда не говорит "я ИИ-ассистент"»), сценарии ответов в чатах, триггеры перехода в воронку, список запретов. Это чистый текст — делается полностью автономно и снимает пункт «разработать имя и легенду» из прогресса.
**Ограничение:** запускать и тестировать в Telegram — только с доступом Леры.

### 3. Контент-пакет под формулу «хук → карусель → готовый промт»
По наблюдению из дайджеста: промт — новая валюта контента. Собрать 5–10 готовых постов с промтами вида «преврати Claude в личного авитолога», под автопубликацию через Publora. Одновременно закрывает GEO (упоминания) и воронку.

### 4. Черновик заявки в Сколково
Формулировки инновационности, описание AI/ML и компьютерного зрения, разделы заявки на основе `22_AI_AGENT_CONCEPT.md`. Текстовая работа целиком.
**Ограничение:** реквизиты юрлица, финмодель, состав команды — только от Леры. Цифры не выдумываю, оставляю плейсхолдеры.

### 5. Чек-лист приёмки парсера для Ивана
Превратить «уточнение 1» из `21_PARSER_REPLY_TO_IVAN.md` в конкретный протокол недельного теста: что логировать, какие пороги считать провалом, форма таблицы результатов. Даёт Ивану готовый инструмент, не трогая его архитектуру.
