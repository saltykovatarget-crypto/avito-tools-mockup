## 🎯 Главная идея

**Аудит объявлений** — диагностика «почему у юзера плохо работает» с конкретным планом действий.

Это **комплекс** из трёх существующих частей:
1. Парсер выдачи ниши (топ-100)
2. Разбор XLS-статистики кабинета юзера
3. AI-диагностика на сравнении

Результат — **готовый ответ** «вот 3 главные проблемы, вот что делать», а не сырые данные.

### Логика

```python
async def run_audit(user_id, chat_id, niche, city, xls_file_id):
    # 1. Списать 290 ₽ (advance_payment_spend_pending)
    advance_payment_service.spend_pending(
        user_id=user_id,
        action=ActionPrice.AUDIT_TOOL,
        related_entity='audit_run',
        idempotency_key=f"audit:{chat_id}:{datetime.now()}"
    )
    
    # 2. Параллельно:
    #    - Парсер выдачи (с кэшем если ниша+город уже парсились)
    #    - Разбор XLS
    parser_task = run_niche_parser(niche, city, use_cache=True)
    xls_task = analyze_xls_stats(xls_file_id)
    parser_data, xls_data = await asyncio.gather(parser_task, xls_task)
    
    # 3. AI-диагностика на сравнении
    diagnosis = await ai_diagnose(
        user_stats=xls_data,
        niche_top=parser_data,
        niche=niche, city=city
    )
    
    # 4. Сохранить audit_run
    audit = save_audit_run(...)
    
    # 5. Подтвердить списание
    advance_payment_service.confirm_pending(audit.transaction_id)
    
    # 6. Push в чат markdown-сообщение от AI
    push_assistant_message(
        chat_id=chat_id,
        text=render_audit_markdown(audit),
        message_type='audit_result',
        related_data=audit.audit_data
    )
```

### Где экономить (кэш парсера ниши)

Если **юзер уже запускал парсер ниши** «гаражные ворота Москва» **за последние 24 часа** — переиспользуем результат **без повторного списания за парсер**.

Это даёт:
- Себестоимость Аудита падает с 80 до 25 ₽ (только XLS-разбор + AI)
- Маржа подскакивает до 91%
- Юзер сэкономил время (3 минуты вместо 5)

```python
def get_niche_parser_for_audit(niche, city, user_id):
    # Проверка кэша
    recent = db.query(ParserResult).filter_by(
        user_id=user_id,
        query=niche,
        city=city
    ).filter(
        ParserResult.created_at > datetime.now() - timedelta(hours=24)
    ).first()
    
    if recent:
        return recent.parser_data  # бесплатно
    
    # Иначе — запустить новый парсер (стоимость уже включена в 290 ₽ аудита)
    return run_niche_parser(niche, city)
```

## 🛡 Edge cases

- **Юзер не в топ-100 в выдаче** → нормально, это часть диагноза. Цена та же.
- **XLS невалидный** → ошибка перед списанием, юзер просит новый
- **Парсер ниши упал** → cancel_pending, деньги возвращаются автоматически
- **Юзер уже запускал аудит этой ниши в этот день** → предлагаем посмотреть прошлый бесплатно, или сделать новый (новые цены/конкуренты)
