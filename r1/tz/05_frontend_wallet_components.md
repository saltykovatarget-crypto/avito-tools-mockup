# ТЗ для Claude Code — Фронтенд кошелька

**Контекст:** работаешь в локальной копии фронтенда AI Авитолог PRO.
Стек: React + TypeScript + Tailwind CSS + shadcn/ui.

**Что делаем:** UI для модели кошелька с пакетами. Бэкенд параллельно делает разработчик.

---

## ПРИНЦИПЫ

- Минимализм. Никаких лишних элементов.
- Tailwind utility-классы.
- Цвета из бренд-кода: #7C3AED (основной), #0D0D1A (фон), #9F67FF (акцент)
- Шрифт: Manrope (уже подключён)
- Анимации плавные, 200ms

## КОМПОНЕНТЫ К СОЗДАНИЮ

### 1. WalletBalance — баланс в шапке

**Где:** правый верхний угол

```
💰 45 ₽   [Пополнить]
```

**Логика:**
- `GET /api/wallet/balance` при загрузке
- Обновление после каждого сообщения в чате (event/polling)
- Баланс < 50 ₽ — иконка оранжевая
- Баланс < 5 ₽ — иконка красная, кнопка подсвечена
- Клик на «Пополнить» → открывает `TopupModal`

**Файл:** `src/components/WalletBalance.tsx`

## ЯНДЕКС МЕТРИКА

Подключение счётчика в `<head>` (через `index.html` или React Helmet).

**События отправлять через `ym(counter, 'reachGoal', name, params)`:**

| Событие | Когда | Параметры |
|---------|-------|-----------|
| `register` | После успешной регистрации | userId |
| `first_message` | Первое сообщение в чате | userId |
| `first_topup` | Первое пополнение | userId, amount, type |
| `topup` | Любое пополнение | userId, amount, type |
| `tool_used` | Использован инструмент | userId, tool_name |

UTM-метки сохранять в localStorage при первом визите, передавать в Метрику с событиями.
