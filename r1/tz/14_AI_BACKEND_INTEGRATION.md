## 1. КОНТЕКСТ ПОЛЬЗОВАТЕЛЯ В СИСТЕМНОМ ПРОМПТЕ

### 1.1 Что подкладывается

Бэкенд при каждом вызове GPT-5.1 добавляет в системный промпт **короткий блок**:

```python
def build_system_prompt(
    user: User,
    balance_rub: int,
    is_new_user: bool,
    parser_used_in_chat: bool,
    start_branch: str,  # из меню старта
) -> str:
    base_prompt = open("prompts/assistant_ru.txt").read()
    
    context = f"""
    
КОНТЕКСТ ПОЛЬЗОВАТЕЛЯ (НЕ ОЗВУЧИВАТЬ ПРЯМО!):
— Баланс: {balance_rub} ₽
— Новичок: {"да" if is_new_user else "нет"}
— Парсер в этом чате: {"запускался" if parser_used_in_chat else "не запускался"}
— Ветка старта: {start_branch}

Используй эти данные ВНУТРЕННЕ для решений:
— Что предлагать (парсер / инструмент)
— Адаптировать глубину ответа
— Понимать на каком этапе пользователь
— Первый ответ строить под выбранную ветку

ЗАПРЕЩЕНО:
— Говорить «у тебя на балансе X ₽»
— Делать математику пополнений в ответе
— Объяснять как работает баланс
"""
    
    return base_prompt + context
```

### 1.2 Значения `start_branch`

| Значение | Что выбрал пользователь |
|---|---|
| `fix_existing` | 🎯 «У меня объявления, мало заявок» |
| `start_from_scratch` | 🚀 «Запуск с нуля» |
| `analyze_stats` | 📊 «Есть статистика» |
| `check_competitors` | 🔍 «Посмотреть конкурентов» |
| `just_ask` | ✏️ «Просто спросить совет» |
| `legacy_migration` | (одноразово) после миграции с подписки — приветствие |

### 1.3 Когда что обновляется

| Поле | Когда |
|---|---|
| `balance_rub` | После каждого списания/пополнения |
| `is_new_user` | true пока нет ни одной транзакции `spend`, далее false навсегда |
| `parser_used_in_chat` | true когда в этом чате был успешный запуск парсера |
| `start_branch` | Фиксируется при создании чата, не меняется |

## 2. ДАННЫЕ ПАРСИНГА И XLS — ЧЕРЕЗ ИСТОРИЮ ЧАТА

**Решение CMO:** не пихать в системный промпт. Передавать как системные сообщения в истории чата.

### 2.1 Парсер — поток

```
1. Юзер запустил парсер через кнопку → списано 190 ₽
2. Парсер отработал на бэкенде
3. В историю чата добавляется системное сообщение role: "system" или role: "assistant" с пометкой:
   "🔍 Парсер ниши готов: запрос '[query]', город '[city]'"
   + structured data в чёткой форме (см. 2.2)
4. Эти данные становятся частью истории
5. AI видит их при следующих запросах автоматически
```

### 2.2 Формат системного сообщения с парсингом

Сообщение должно содержать структурированный JSON в форматированной выдаче. GPT-5.1 лучше читает данные в человекочитаемом виде с метками — не голый JSON.

Пример системного сообщения:

```markdown
🔍 **РЕЗУЛЬТАТ ПАРСИНГА КОНКУРЕНТОВ**

**Контекст:**
- Запрос: гаражные ворота
- Город: Москва
- Категория: Дом и дача / Ворота / Секционные ворота для гаража
- Дата: 28.05.2026

**Сводка рынка:**
- Объявлений всего: 100
- Уникальных продавцов: 44
- Средняя цена: 58 707 ₽
- Медианная цена: 55 415 ₽
- Используют продвижение: 85%
- Доставка: 0%
- Просмотров в день: 485

**Топ-5 лидеров:**

| # | Аккаунт | Объявлений | Продвинутых | Просм/день | Доля today |
|---|---------|------------|-------------|------------|------------|
| 1 | DoorHanRu | 11 | 11 | 180 | 37.1% |
| 2 | (без имени) | 10 | 6 | 112 | 23.1% |
| 3 | Сергей | 8 | 8 | 45 | 9.3% |
| 4 | АвтоВорота-Москва | 6 | 6 | 39 | 8.0% |
| 5 | Век ворот | 9 | 9 | 15 | 3.1% |

**Топ-10 объявлений по позиции:**

1. "Ворота Гаражные Секционные Автоматические" — 54 773 ₽ — DoorHanRu — 117 просм/день — VAS: да
   URL: https://www.avito.ru/...
2. ... (ещё 9)

**Ценовые сегменты:**

- Эконом (до 38 000 ₽): 18 объявлений, средне 12 просм/день
- Средний (38 000 — 72 000 ₽): 56 объявлений, средне 8 просм/день
- Премиум (от 72 000 ₽): 26 объявлений, средне 5 просм/день

**Паттерны заголовков:**

- Частые слова: ворота, гаражные, секционные, автоматические, под ключ
- Заглавных первых букв: 4/10
- Бренд в заголовке: 6/10
- Цены в заголовке: 0/10
- Средняя длина: 35 символов

**Визуальные паттерны (топ-10 фото):**

- продуктовое: 38%
- контекстное: 24%
- баннер: 18%
- коллаж: 12%
- схема: 8%
- Текстовый оверлей: 42%
- Цена на фото: 28%
- Логотип бренда: 35%
- Лучшие типы фото (по просмотрам/день): продуктовое (24), контекстное (18)

**Ключевые инсайты:**

1. Лидер DoorHanRu занимает 37% доли рынка с 11 продвинутыми объявлениями
2. 85% продавцов используют VAS — без продвижения позиций не получить
3. Доставка не используется (0%) — точка дифференциации
4. Медиана цен 55 415 ₽, разброс 25–250 тыс ₽
5. У топ-1 первое фото без текста на изображении, у 42% выдачи есть текстовый оверлей
6. Топ заголовков используют 4 ключа: ворота + гаражные + секционные + автоматические
```

### 2.3 XLS-разбор — поток

```
1. Юзер загрузил XLS файл → файл лежит, ничего не списано
2. AI видит сообщение пользователя с приложенным файлом → 
   предлагает запустить анализ (шаблон 2.2 в файле формулировок)
3. Юзер нажал "Проанализировать" (или явно согласился) → 
   списывается 50 ₽
4. Бэкенд парсит XLS и формирует системное сообщение с разбором
5. Сообщение от AI приходит в чат БЕЗ дополнительного списания 5 ₽
   (флаг в messages.py: если ответ часть analyze_xls — не списывать)
6. AI использует данные из системного сообщения для дальнейшей работы
```

### 2.4 Формат системного сообщения с XLS

Аналогично парсингу — структурированно, с метками:

```markdown
📊 **РЕЗУЛЬТАТ АНАЛИЗА XLS СТАТИСТИКИ**

**Файл:** Статистика_с_2026-04-27_по_2026-05-26.xlsx
**Период:** 27.04.2026 — 26.05.2026 (30 дней)

**Зафиксировано:**
- Тип проекта: товар
- Категория: Дом и дача / Ворота
- Средний чек: 85 000 ₽
- Регионов: 2 (Москва + МО, СПБ + ЛО)
- Объявлений: 437 → масспостинг
- Применённый норматив CTR: 4–7%

**Воронка:**
- Показы: 6 972
- Просмотры: 283 → CTR 4.1%
- Контакты: 8 → конверсия 2.8%
- Расход: 10 478 ₽ → CPL 1 310 ₽

**Точка потери:** CTR
Детали: 4.1% при норме 4-7% для товара, проседаем на показы→просмотры

**По типам товара:**

| Тип | Объявлений | CTR | Контакты | Расход | CPL |
|-----|-----------|-----|----------|--------|-----|
| Секционные ворота | 178 | 4.9% | 7 | 6 140 | 877 |
| ... | ... | ... | ... | ... | ... |

**По регионам:**

| Регион | Объявлений | Показы | Контакты | CPL |
|--------|-----------|--------|----------|-----|
| Москва + МО | 215 | 3 159 | 4 | 865 |
| СПБ + ЛО | 222 | 3 813 | 4 | 1 738 |

**Топ-5 объявлений по контактам:**

1. ID 8139015503 — СПБ — На ворота — 746 показов — 1 контакт — CPL 2 467 ₽
   URL: https://www.avito.ru/sankt-peterburg/dlya_doma_i_dachi/rolstavni_i_rolletnye_vorota_doorhan_ot_zavoda_8139015503
2. ...

**Распределение показов:**
- 0 показов: 0
- 1–10: 324
- 11–50: 89
- 51–200: 19
- 200+: 5

**Возраст объявлений:**
- Среднее: 5 дней
- Моложе 5 дней: 225 (статистика ещё накапливается)
```

### 2.5 Почему так

— Системный промпт остаётся коротким (быстрее, дешевле)

— GPT-5.1 читает структурированный markdown лучше чем JSON

— Данные становятся частью истории — можно вернуться через неделю и они на месте

— Просто реализовать: бэкенд формирует строку и пушит в БД сообщений

## 3. ОПЛАТА И ОБРАБОТКА XLS — ВАЖНЫЙ ФЛАГ

### 3.1 Логика списания

```python
# backend/app/services/messages.py

async def send_ai_response(
    user_id: int,
    chat_id: int,
    response_text: str,
    is_part_of_paid_action: bool = False,
    parent_action: str = None,  # "analyze_xls" / "parser_niche" / etc
):
    """
    Сохранить ответ AI и списать 5 ₽ если это обычный ответ.
    Если ответ — часть платного действия (анализ XLS, парсер),
    дополнительно НЕ списываем.
    """
    message = await save_message(chat_id, "assistant", response_text)
    
    if not is_part_of_paid_action:
        wallet_service.spend(
            user_id=user_id,
            action=ActionPrice.CHAT_MESSAGE,
            related_entity='chat_message',
            related_entity_id=message.id,
        )
    
    return message
```

### 3.2 Сценарии

| Действие | Что списывается |
|---|---|
| Юзер написал «расскажи про CTR» | 5 ₽ за ответ AI |
| Юзер загрузил XLS файл | 0 ₽ |
| AI предложил анализ за 50 ₽ | 5 ₽ за это предложение |
| Юзер согласился, нажал «Проанализировать» | 50 ₽ за анализ |
| AI выдал результат анализа | 0 ₽ (часть analyze_xls) |
| Юзер пишет «а что по топу?» | 5 ₽ за следующий ответ AI |

### 3.3 Аналогично для парсера

— Юзер нажал «Запустить парсер» → 190 ₽

— AI выдал «парсер готов, вот результаты» → 0 ₽ (часть `parser_niche`)

— Дальше обычные ответы по 5 ₽

## 4. МЕНЮ СТАРТА — ПЕРЕДАЧА ВЕТКИ

### 4.1 Что делает фронт

При выборе ветки в меню старта:

1. Создаёт новый чат
2. Сохраняет `start_branch` в метаданных чата
3. Отправляет первый «системный» промпт пользователя (или пустой)

```typescript
async function selectStartBranch(branch: StartBranch) {
  const chat = await createChat({ start_branch: branch });
  
  // Если ветка имеет автопромпт — отправляем
  if (branch !== 'just_ask') {
    await sendMessage(chat.id, getInitialPromptForBranch(branch));
  }
  
  router.push(`/chat/${chat.id}`);
}
```

### 4.2 Автопромпты по веткам

| Ветка | Первое сообщение пользователя |
|---|---|
| `fix_existing` | «Помоги разобраться почему мало заявок с моих объявлений» |
| `start_from_scratch` | «Хочу запустить продажи на Авито с нуля» |
| `analyze_stats` | «У меня есть XLS статистика из кабинета Авито, помоги разобрать» |
| `check_competitors` | «Хочу проанализировать конкурентов в моей нише через парсер» |
| `just_ask` | (пустой — открывается обычное поле ввода) |

### 4.3 Что делает бэкенд

При первом запросе AI в новом чате:

1. Читает `start_branch` из метаданных чата
2. Передаёт его в системный промпт как `КОНТЕКСТ ПОЛЬЗОВАТЕЛЯ → Ветка старта: ...`
3. AI строит первый ответ под ветку (см. шаблоны 1.1-1.5)

## 7. LEGACY МИГРАЦИЯ — ОДНОРАЗОВОЕ ПРИВЕТСТВИЕ

### 7.1 Логика

Решение CMO: отдельного режима не делаем. Одно приветственное сообщение и дальше обычная работа.

После миграции подписчика:

1. Конвертируется остаток подписки в баланс (формула: дней до конца × тариф / 30)

2. В первый новый чат (или первый ответ в существующем) бэкенд **один раз** добавляет приветственное системное сообщение:

```
Привет! Мы переехали на модель кошелька — больше никаких лимитов и подписок.

Твой остаток подписки конвертирован в баланс — там сейчас [X] ₽.

Дальше платишь только за то что используешь:
— Ответ AI: 5 ₽
— Парсер ниши: 190 ₽
— Анализ статистики: 50 ₽
— Фото: 19 ₽

Готов продолжить? Выбери ветку выше или просто пиши вопрос.
```

3. Дальше — обычная работа, флаг `legacy_migration` сбрасывается.

### 7.2 Что AI должен знать

В системном промпте есть правило: если пользователь спрашивает про подписки / тарифы / переезд — короткий ответ (см. шаблон 3.5) и возврат к задаче.
