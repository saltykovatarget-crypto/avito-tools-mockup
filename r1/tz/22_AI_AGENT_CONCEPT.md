## ГЛАВНЫЙ ТЕЗИС

**AI Авитолог PRO — это не «сервис аналитики Авито». Это автономный ИИ-агент, который выполняет работу профессионального авитолога.**

Разница принципиальна:
- Сервис аналитики = показывает данные, человек думает сам
- ИИ-агент = сам анализирует, принимает решения, действует, советует

Для позиционирования (Сколково, инвесторы, клиенты) всегда использовать формулировку:

> **«Автономный ИИ-агент для управления продажами на маркетплейсах с компьютерным зрением и мультимодальным анализом»**

Не «парсер Авито» — это не инновация. Именно ИИ-агент — это ИИ-направление, приоритетное у Сколково.

---

## АРХИТЕКТУРА АГЕНТА

Продукт устроен как классический ИИ-агент — мозг + органы чувств + инструменты + память.

```
              🧠 МОЗГ (LLM: GPT-5 / Claude)
              Принимает решения, анализирует, формулирует советы
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
    👁 ГЛАЗА             🔧 РУКИ             📚 ПАМЯТЬ
    Vision-анализ        Инструменты         База знаний
    фото объявлений      (действия)          (контекст)
```

### 🧠 Мозг
LLM (GPT-5 в продукте, Claude для разработки). Системный промпт задаёт личность и методологию авитолога (см. `11_AI_SYSTEM_PROMPT.md`). Мозг не считает математику сам — агрегации делает бэкенд, мозг формулирует выводы из фактов.

### 👁 Глаза (компьютерное зрение)
Vision-анализ фото объявлений. Ключевая инновация — агент **видит** визуал конкурентов и понимает что работает в нише (баннеры, люди в кадре, тип фото). Без vision агент выдаёт правдоподобные но неверные гипотезы (см. кейс DoorHan в `15_PARSER_VISION_ARCHITECTURE.md`).

### 🔧 Руки (инструменты / tools)
Как у Claude Code есть Read/Bash/Git, так у AI Авитолога — набор инструментов, которые он **сам решает** когда вызвать:

| Инструмент | Что делает | Статус |
|---|---|---|
| `parse_niche` | Парсит нишу, собирает конкурентов | R1 |
| `analyze_photo` | Vision-разбор фото объявления | R1 |
| `check_positions` | Проверяет позиции объявлений | R2 |
| `generate_title` | Пишет заголовки под нишу | R1 |
| `generate_photo` | Генерация/обработка фото объявления | R2 |
| `apply_vas` | Управляет продвижением (VAS) | R2+ |
| `send_notification` | Пишет клиенту в Telegram | R1.5 |

### 📚 Память (контекст)
- Системный промпт — кто агент, как думает
- Данные парсинга — что агент «видел» в нише
- История диалога с клиентом
- Профиль клиента и его объявления
- Function calling для доступа к деталям без перегрузки контекста

## УРОВНИ АВТОНОМНОСТИ (роадмап ценности)

Ключевая долгосрочная идея — движение от «советует» к «делает сам».

```
Уровень 1 (R1, сейчас):
  Агент СОВЕТУЕТ, человек делает
  → «Подними это объявление, смени заголовок на...»

Уровень 2 (R2):
  Агент ДЕЛАЕТ С ПОДТВЕРЖДЕНИЕМ
  → «Готов поднять 3 объявления и сменить 2 заголовка. Подтверждаешь?»

Уровень 3 (долгосрочно):
  Агент работает ПОЛНОСТЬЮ АВТОНОМНО
  → сам поднимает, меняет цены, отвечает клиентам, ведёт аккаунт
```

**Ценностное сообщение уровня 3:**
> «Наняли ИИ-сотрудника вместо авитолога за 50 000 ₽/мес»

Это то, что отличает продукт от простых парсеров и обосновывает высокую оценку для инвесторов.

## ПОЧЕМУ ЭТО ИННОВАЦИЯ (для Сколково)

Критерий Сколково — инновационность + IT/AI-составляющая. У проекта есть всё:

✅ **AI/ML** — LLM-агент с рассуждением, не скриптовый бот
✅ **Компьютерное зрение** — мультимодальный vision-анализ изображений
✅ **Собственная разработка** — парсер, бэкенд, агрегации, алгоритмы инсайтов
✅ **Автономность** — агент сам выбирает инструменты и действия
✅ **Реальная монетизация** — работающая бизнес-модель (авансовые платежи за услуги)
✅ **Приоритетное направление** — «Искусственный интеллект» у Сколково в приоритете

**Что подчёркивать в заявке:**
- Мультимодальность (текст + изображения)
- Автономное принятие решений агентом
- Компьютерное зрение для анализа визуального контента
- Не «парсинг», а «интеллектуальная система анализа и управления»

## СВЯЗЬ С ДРУГИМИ ЧАСТЯМИ ПРОЕКТА

- **Telegram-агент** (из задач) — это тот же ИИ-агент, но с входом через Telegram. Один мозг, разные каналы.
- **Парсер** — это «глаза и руки» агента для сбора данных.
- **Vision-анализ** — ключевой сенсор, отличающий от конкурентов.
- **Уведомления в Telegram** — агент проактивно сообщает клиенту («парсер готов», «позиция упала»).
