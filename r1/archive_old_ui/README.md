# Архив старых UI-мокапов

Эти HTML-мокапы были сделаны под **старую подписочную модель** (тарифы 1 590 / 4 290 / 9 990 ₽, квоты, биллинг).

Сейчас сервис на wallet-модели (авансовый платёж, без подписок) — эти мокапы **не использовать как референс**.

## Что здесь и почему устарело

- `cabinet.html` — дашборд с CTA «Шаг 3 из 10», старая шапка с квотами
- `parser.html` — форма парсера со старыми цифрами (4 пакета по подписке)
- `wallet.html` — кошелёк со счётчиками «прогонов» (квоты), под старую модель
- `billing.html` — биллинг подписок (в wallet-модели биллинга вообще нет, только разовые пополнения)

## Что использовать вместо них

Актуальные референсы:
- **Лендинг wallet-модели**: http://localhost:5173/ (живой dev-сервер у Леры)
- **Чат UI**: `../chat.html` (прогресс 10 шагов остался актуальным)
- **Отчёт парсера**: `../parser-report.html` (раскладка визуально валидна)

Новый UI кабинета (на wallet-модель) Лера делает прямо в кодовой базе — `~/Desktop/avitolog-2026-05-15-lite-for-audit/app/src/components/`:
- `WalletBalance.tsx` — баланс в шапке
- `WalletPage.tsx` — страница `/wallet` с историей
- `TopupModal.tsx` — модалка пополнения
- `ParserPanel.tsx` — форма запуска парсера (URL Авито)
- `XLSUpload.tsx` — анализ статистики кабинета
- `PositionCheckPanel.tsx` — проверка позиций

Все компоненты уже работают на mock-данных, надо подключить к реальному API.
