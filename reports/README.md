# Отчёты агентов

Сюда облачные агенты складывают отчёты о своей работе. Файлы попадают в GitHub, а оттуда — в Obsidian на Mac через синхронизацию (плагин Obsidian Git).

## Формат

Один файл на день дежурства:

```
reports/2026-08-17-дежурный.md
reports/2026-08-18-дежурный.md
```

## Структура отчёта

```markdown
# Дежурство 17.08.2026

## Что сделал
- ...

## Готово к просмотру
- файл / ссылка / коммит

## Нужно решение Леры
- вопрос 1
- вопрос 2

## Что мешает работать
- каких доступов не хватает
```

## Правила

- Коротко, по делу, без воды
- Не выдумывать активность: если продвинуть нечего — так и написать
- Токены, пароли и ключи в отчёты не писать никогда
- Каждый отчёт — отдельный коммит с понятным сообщением
