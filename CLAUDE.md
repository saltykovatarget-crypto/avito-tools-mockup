## 2. Telegram-агент (псевдо-человек)

**Концепция:** Telegram-аккаунт / персонаж, который выглядит как реальный человек, но внутри работает ИИ (AI Авитолог PRO).

**Роль персонажа:**
- Авитолог-консультант (отвечает как опытный специалист по Авито)
- Возможно от имени: вымышленный помощник / ассистент (придумать имя)
- Тональность: живая, человечная, без "я ИИ-ассистент"

**Функции:**
- Консультирование по Авито: объявления, VAS, позиции, стратегия
- Активная работа в чатах — писать, рекомендовать, отвечать на вопросы
- Воронка: чат → подписка на Telegram-канал → переход на сервис AI Авитолог PRO

**Воронка:**
```
Пользователь в чате → Агент отвечает / помогает
       ↓
Рекомендует Telegram-канал (подписаться)
       ↓
В канале → ведёт на AI Авитолог PRO (сервис)
```

**Технически:**
- Telegram Bot API (userbot через Telethon/Pyrogram или обычный бот)
- Подключить AI Авитолог PRO или Claude API для ответов
- Обучить на манере общения авитолога
- Настроить триггеры для продвижения

## 3. Инструменты команды (использовать в работе)

### Sentry — отслеживание ошибок в продакшне
**Репо:** github.com/getsentry/sentry | **SDK установлен:** `sentry-sdk` (Python)

**Когда использовать:**
- Подключить к бэкенду FastAPI и парсеру с первого дня продакшна
- Sentry ловит исключения, собирает стектрейс + данные запроса в момент падения
- Вместо "баг не воспроизводится" — точный snapshot что произошло

**Как подключить к FastAPI (Ивану):**
```python
import sentry_sdk
sentry_sdk.init(dsn="https://xxx@sentry.io/yyy", traces_sample_rate=0.2)
```

**Как использовать Лере:** завести аккаунт на sentry.io (бесплатный план до 5k ошибок/мес), дать Ивану DSN-ключ.

---

### Plausible — веб-аналитика без куки-баннеров
**Репо:** github.com/plausible/analytics

**Когда использовать:**
- Подключить к сайту AI Авитолог PRO вместо Google Analytics
- Показывает: откуда приходят пользователи, какие страницы смотрят, где уходят
- Не требует куки-баннера (GDPR-compliant из коробки)
- Self-hosted на своём сервере или облачный план от $9/мес

**Как подключить (1 строка в HTML):**
```html
<script defer data-domain="aiavitologpro.ru" src="https://plausible.io/js/script.js"></script>
```

**Когда добавить:** при запуске лендинга (R1).

---

### Plane — трекер задач команды
**Репо:** github.com/makeplane/plane

**Когда использовать:**

- Вместо задач в мессенджерах и таблицах
- Self-hosted (Docker) или cloud.plane.so (бесплатно до 12 человек)

**Как начать:** зарегистрироваться на cloud.plane.so, создать проект "AI Авитолог PRO", перенести задачи из ТЗ в бэклог.

**Когда использовать:**
